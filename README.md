# AI Architects — Catapult

This is the project repository for the **AI Architects** team, built during the **Catapult** program. Catapult is a hands-on engineering and innovation program where teams design, build, and present real technical projects over the course of the program.

Each project lives in its own folder with its own README covering how to set it up and run it.

## Projects

| Project | Folder | Description |
|---|---|---|
| Camera Canvas | [camera-canvas/](camera-canvas/README.md) | Real-time neural style transfer webcam app — apply painterly art styles to a live camera feed, or generate artwork from a still photo |
| Stepper Control Panel | [stepper-control/](stepper-control/README.md) | GUI to drive five 28BYJ-48 stepper motors by angle, speed, or step jogs — Arduino Mega + pygame, runs in mock mode with no hardware |

## Documents

The `documents/` folder contains reference material and deliverables produced during the program. The `samples/` folder holds example posters and reports from other Catapult teams, kept here as reference.
